# Native v5 Pitchfork Drawing Implementation Plan

> **For agentic workers:** Use this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a three-anchor Andrews Pitchfork to the isolated native-v5 chart, with correct parallel projection and the existing scoped drawing lifecycle.

**Architecture:** Store three UTC candle/price anchors and derive the median through pivot 1 and the midpoint of pivots 2 and 3, plus parallel rails through pivots 2 and 3. On every render update, map the saved anchors through the current time/price scales, derive the three lines in plot coordinates, and clip their rays to the visible pane; recompute after data, pan/zoom, or resize. Persist the three anchors only, never derived pixel geometry. Reuse the native-v5 drawing tool, persistence, undo/redo, selection, duplicate/delete, and portable-layout pathways. Keep production v4 mounted and native v5 opt-in.

**Tech Stack:** TypeScript, Lightweight Charts 5.2.1 series primitives, Python schema validators, Node/Chromium smoke tests.
