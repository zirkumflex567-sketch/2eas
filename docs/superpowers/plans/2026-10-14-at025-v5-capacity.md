# AT-025 native v5 capacity implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align the isolated native v5 renderer with the master-spec target of 5,000 bars, 20 active indicator instances, and 1,000 selectable/persistent drawings, with bounded storage and recorded browser measurements.

**Architecture:** Add one shared indicator-instance bound and one shared native-drawing bound, and size private browser persistence/portable transfer for the supported drawing count. Extend the Chromium fixture to exercise a full representative 5k/20/1k chart, sample selection at the beginning/middle/end, and scoped reload/transfer; record timings as environment-specific evidence, while leaving reference-hardware FPS, mobile budgets, and production migration open until measured on those targets.

**Tech Stack:** TypeScript, Lightweight Charts 5.2.1, localStorage schema v2, portable schema v1, Playwright Chromium.
