# Ichimoku Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explainable, read-only Ichimoku Cloud indicator to Chart Studio Beta and the isolated native-v5 adapter, with bounded settings and exact formula/render parity.

**Architecture:** Keep the standard midpoint calculations in the shared pure indicator module. Tenkan, Kijun and Chikou retain their source-candle relationship; Senkou A/B are projected forward by the configured number of observed-bar intervals. For the tail beyond observed data, project only when an explicitly supported timeframe cadence is supplied; projected points carry source timestamps and have no synthetic OHLC or candle readout. Without cadence evidence, stop projection at the final observed candle. Render the cloud fill only between the spans and split each polygon at Senkou A/B crossings, including equality endpoints. The renderer does not consume future OHLC. Account-local settings and SQLite schema-v1 validation use the existing indicator contract.

**Tech Stack:** Existing Chart Studio JavaScript engine, SQLite workspace validator, TypeScript Lightweight Charts v5 adapter, Node tests, Chromium smoke.

## Formula and safety contract

- Defaults: Tenkan 9, Kijun 26, Senkou B 52, displacement 26 bars.
- Tenkan/Kijun/Senkou B are `(highest(high, n) + lowest(low, n)) / 2` over the complete trailing window.
- Senkou A is `(Tenkan + Kijun) / 2` at the source candle and is plotted `displacement` observed intervals forward; Senkou B is calculated at its own source candle and plotted the same way.
- Chikou is the current close plotted `displacement` observed bars backward. Each point retains source-time metadata; the data window must not represent that projected-back value as if it were known at the target candle.
- No output is invented during any component's warm-up. No future candle values enter a calculation. Existing target bars are selected by observed-bar index even across gaps/weekends. For forward tail projection, use only a validated explicit fixed-seconds cadence (M1 60, M5 300, M15 900, M30 1800, H1 3600, H4 14400, D1 86400, W1 604800); do not infer exchange sessions, skip weekends, or adjust for DST. Otherwise cap at the last observed bar rather than infer from gaps. Projected coordinates have sourceTime and projected metadata, with no synthetic OHLC/data-window candle. Chikou readouts are attributed to sourceTime and cannot be surfaced as information known at its target candle.
- Bounds: Tenkan/Kijun/Senkou B periods 2–200, displacement 0–200. Reject invalid updates atomically.
- Read-only indicator; no decision, order, broker-write, MT5, Strategy Tester, or backtest integration.

## Acceptance

- Exact periods, line values, warm-up and source/target time relationships are checked against hand-computed fixtures, including irregular gaps, timeframe-only tail projection, and readout source attribution.
- Replacing a forming candle recomputes the same source outputs without appending or changing any other candle; history replacement and account changes clear/rebuild affected series.
- Invalid settings are rejected before existing settings/series mutate.
- Account-local UI persistence and SQLite round-trip preserve valid settings; corrupt or out-of-range snapshots are rejected.
- Native v5 matches Beta for every output component and counts the five-line group once under the shared 20-indicator limit.
- Physical target hardware, touch/DPI duration, production v5 cutover and rollback are not inferred from headless tests and remain separately gated.
