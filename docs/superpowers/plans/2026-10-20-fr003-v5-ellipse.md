# FR-003 V5 native ellipse

## Goal
Add an isolated V5 ellipse drawing primitive using two UTC/price anchors. Match native drawing lifecycle: validated creation/update/remove, selection handles and drag, visibility/lock, undo/redo, scoped persistence, portable JSON, and placement tool.

## Boundaries
- Keep V5 opt-in and read-only with respect to MT5; no broker routes or mutations.
- Do not change the production V4 chart.
- Ellipse is axis-aligned in chart time/price coordinates, with a two-corner bounding box and no fill by default.

## Validation
1. Add Chromium contracts for shape API/geometry, placement-tool activation, drag/rollback, visibility/lock, history, scoped reload and JSON transfer, plus preview-toolbar activation.
2. Observe the expected RED failure before implementation.
3. Implement the smallest integration across primitive registry, snapshots and input lifecycle.
4. Run V5 TypeScript check/build and the isolated Chromium smoke.
5. Update task documentation with completed scope and remaining items.
