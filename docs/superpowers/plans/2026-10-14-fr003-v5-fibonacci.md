# FR-003 native v5 Fibonacci drawing plan

**Goal:** Render the six required Fibonacci retracement levels from two exact loaded UTC candle/price anchors and preserve the drawing through the existing scoped drawing lifecycle.

**Scope:** Isolated native v5 adapter and browser fixture only. No production chart cutover, MT5 access or broker writes. Ratio convention follows the master spec: each price is `startPrice + (endPrice - startPrice) * ratio`; 0 is anchor A and 1 is anchor B. Include the default extension levels 1.272, 1.618 and 2.618.
