# FR-002 ATR Bands vertical slice

## Goal

Add a read-only ATR Bands indicator to the Chart Studio Beta catalog and shared indicator engine, persist it through the existing account-scoped browser profile and SQLite workspace contract, and provide formula/render parity through the isolated native-v5 adapter. This is an indicator addition, not a trading signal or strategy recommendation.

## Definition

- Center: close-price SMA, default period 20.
- Volatility: Wilder ATR, default period 14, with true range including prior-close gaps.
- Bands: `SMA(close, period) ± multiplier * WilderATR(atrPeriod)`, default multiplier 2.
- Bounds: each period 2–200; multiplier 0.1–10 in 0.1 steps.
- An output exists only when both the full SMA and ATR warm-up are available; no forward fill or look-ahead.
- Forming-bar updates replace the current value. A closed candle updates only from its own OHLC and prior close.
- Settings are scoped by account/symbol/timeframe where the existing profile engine supports scope; workspace v1 accepts the new optional kind without breaking old documents.

## Files and sequence

1. Add failing formula, bounds, warm-up, and input immutability contracts in `scripts/test_chart_studio_indicators.cjs`.
2. Add ATR Bands to `static/chart-studio-indicators.js` and `static/chart-studio-catalog.js`; cover series, readout, settings restoration, and catalog in `scripts/smoke_chart_studio_beta.cjs`.
3. Extend strict workspace validation in `chart_studio/workspaces.py` and round-trip/bad-input coverage in `tests/test_chart_studio_workspaces.py`.
4. Add the same formula and bounded grouped overlay API to `chart_studio_v5/src/adapter.ts`; compare native-v5 values, warm-up, forming replacement, append, collision, limit, readout, and removal against the Beta reference in a Chromium contract.
5. Run focused tests and both native-v5 builds, inspect the diff, update `docs/OPEN_TASKS.md`, and request independent review.

## Acceptance limits

This slice does not switch production from v4 to v5. Hardware/DPI/touch/duration gates remain open. It does not connect to or mutate MT5 and does not run any backtest/Strategy Tester.
