# CCI Indicator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver Commodity Channel Index as a configured, account-scoped oscillator in ChartStudio Beta and the isolated native v5 adapter, with correct data-window and persisted-view behavior.

**Architecture:** Use one documented CCI contract in both existing math layers: typical price `(high + low + close) / 3`, rolling period mean, mean absolute deviation around that mean, and `(typical - mean) / (0.015 * deviation)`. Use a 20-bar default, valid periods 2–200, first output at `period - 1`, and value 0 when deviation is zero. Follow the repository's established separate Beta and native-v5 math engines and enforce exact-series parity in Chromium; do not refactor unrelated indicators. Extend the existing Beta panel/workspace schema and native v5 oscillator stream/adapter without changing production renderer cutover or any broker path. Repair the workspace validator's existing rejection of the already-supported Stochastic instance with its exact `period/smoothK/smoothD` schema while touching that integration.

**Tech Stack:** Browser JavaScript, TypeScript, Lightweight Charts v5 adapter, SQLite workspace validators, Node contracts, Chromium smoke.

---

## File map

- `static/chart-studio-indicators.js`: Beta registry, pure CCI calculation, defaults, parameter bounds, pane and data-window readout.
- `static/chart-studio-catalog.js`: expose CCI in search and the existing oscillator add flow.
- `static/chart-studio-oscillators.js`: support CCI in Beta multi-instance normalization, pane series, account-local editor state, and workspace-facing export/import.
- `chart_studio/workspaces.py` and `tests/test_chart_studio_workspaces.py`: strict CCI kind and 2–200 period persistence validation.
- `chart_studio_v5/src/oscillators.ts`: batch CCI plus bounded incremental updates whose forming-bar replacement restores its pre-bar checkpoint.
- `chart_studio_v5/src/adapter.ts`: CCI allowlists, scoped-view restoration, pane series, component/readout labels and update API.
- `scripts/test_chart_studio_indicators.cjs`, `scripts/test_chart_studio_oscillators.cjs`, `scripts/smoke_chart_studio_oscillators.cjs`, and `scripts/smoke_chart_studio_v5.cjs`: deterministic math, validation, account isolation, native parity, stream replacement, pane/readout and persisted restore checks.
- `docs/OPEN_TASKS.md` and `docs/CHART_STUDIO_V5_RFC.md`: record exactly what the implementation proves while keeping production cutover and hardware acceptance open.
