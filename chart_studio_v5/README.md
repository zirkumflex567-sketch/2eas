# Isolated native Chart Studio v5 renderer

Experimental TypeScript browser adapter. **No MT5 access, broker mutation or dashboard cutover.**

Build on Node.js 22:

```sh
npm install --package-lock=false --no-audit --no-fund
npm run check
npm run build
```

Run `node scripts/smoke_chart_studio_v5.cjs` from repository root with Playwright installed and Chromium available. It starts a local fixture server on port 8872, uses native v5 chart/line/pane/volume APIs, validates account isolation, rejects stale and malformed bars, reads exact-time OHLC/volume/indicator values with source and warm-up states, exercises price/time gestures, keyboard nudges for selected drawings with single-step undo/redo, and a bounded anchored text annotation. Selected trend-line, rectangle and Fibonacci anchors show 12-pixel canvas handles; both endpoints support pointer dragging snapped to loaded candles, preserve the opposite anchor, and have Escape rollback, lock rejection, and one-gesture history contracts. A CDP-injected touch drag also passes at 390 CSS px and 150% DPR without prior hover state; physical-device acceptance remains open. The adapter exposes `drawingAnchorPosition(id, anchor)` using public chart coordinates. It also draws a native three-anchor parallel channel with baseline, offset boundary and dashed midpoint; create/update/remove, all three pointer-dragged anchors, untouched-anchor preservation, Escape rollback, lock rejection, keyboard nudging, anchor coordinates, zero-width and unloaded-candle rejection, shared object limit, scoped reload and undo/redo are covered by Chromium. The channel accepts a vertical baseline and preserves stored UTC/price anchors outside the loaded window. A separate AT-025 fixture loads 5,000 bars, exercises 20 mixed overlay/pane indicators and 1,000 drawings, exports/imports and reloads all drawings, and checks sampled hit selection. Its 523,385-byte near-limit snapshot proves oldest-history trimming preserves all 1,000 drawings, and a multibyte oversized snapshot verifies byte-based rejection; environment and timings are recorded in `docs/AT025_CHROMIUM_CAPACITY_2026-10-14.md`. The run is not target-hardware FPS acceptance. It also persists two-anchor trend lines and filled rectangles, a forward-projected ray, and standard/custom Fibonacci retracement levels using exact loaded UTC candle/price coordinates. The engine exposes validated `visibleLogicalRange()` and `setVisibleLogicalRange(range)` methods around the public time-scale API; Chromium checks exact trend anchor geometry over 1,200 loaded bars and wide/narrow viewport ranges. Passing `{symbol, timeframe}` as the third `createStudioV5` argument opts into private scoped localStorage schema v2, which persists strict bounded undo/redo history and migrates valid private schema-v1 snapshots; portable JSON export/import remains schema v1 with no history or account ID. Import requires matching symbol/timeframe, a clean canvas, ready storage and valid loaded candle anchors; invalid or conflicting imports are rejected before changing drawings. The fixture verifies eleven concrete native drawings, including a parallel channel, survive browser reload and JSON transfer, checks history ordering and create/delete restoration, keeps data isolated by account/timeframe, rejects malformed/conflicting imports and corrupt history, and confirms zero broker writes; it records `output/visual-smoke/chart-studio-v5-selected-handles.png`, `chart-studio-v5-touch-390-dpr150.png` and `chart-studio-v5-poc.png`.

The adapter also exposes `addMovingAverage` for independently configured EMA/SMA/WMA/RMA/SMMA overlays computed from loaded OHLC candles. It supports `close`, `open`, `high`, `low`, `hl2`, `hlc3` and `ohlc4`, periods 1–1,000 and display-only shifts from −500 to +500 bars. Replacing candle history recalculates managed instances; forming-bar updates use cached prior values and update only affected points. Exact-time data-window readouts preserve warm-up gaps. The smoke compares all five formulas and seven sources with the current beta calculation, samples shifts from −2 to +2, exercises same-bar/new-bar updates, and checks independent EMA-20 styles/configurations. This is calculation/rendering capability, not production editor/profile migration.

The adapter also exposes `addOscillator`, `updateOscillator`, `moveOscillator` and `removeOscillator` for bounded Wilder RSI/ATR/ADX and MACD groups. Parameters and colors remain instance-local; MACD's line, signal and histogram share a native pane, as do ADX/+DI/−DI. Native price scales auto-scale and show axis/value labels. Forming/new bars recalculate oscillator values from the loaded history and update only the final native series point and readout; full calculation-state caching is not yet implemented. The Chromium smoke compares values and UTC alignment against `ChartStudioIndicators.calculate`, including flat prices, warm-up, invalid settings, config isolation, account cleanup, 8-pane and shared 20-indicator limits. This remains isolated v5 adapter evidence; production editor/profile wiring, v4/v5 parity and target hardware acceptance remain open.

The compiled bundle is used exclusively by `fixture.html` at this stage. To migrate the main dashboard, implement and pass the separate gates in `docs/CHART_STUDIO_V5_RFC.md`.
